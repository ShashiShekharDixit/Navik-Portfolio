## SVG Details

### SVG Specifications:
- **ViewBox**: 0 0 100 100 (consistent)
- **Namespace**: xmlns="http://www.w3.org/2000/svg"
- **Stroke-width**: 2-3px (clean lines)
- **Stroke-linecap**: round (smooth edges)
- **Stroke-linejoin**: round (professional corners)

### Gradient Details:
- **Type**: Linear gradients
- **Direction**: x1="0%" y1="0%" x2="100%" y2="100%" (diagonal)
- **Stops**: 0% to 100% with color transitions
- **Opacity**: 1 (full visibility)

### Animation on SVGs:
```css
.pillar-icon svg {
  animation: rotateIcon 20s linear infinite;
}

.pillar:hover .pillar-icon svg {
  animation-duration: 8s; /* Speeds up on hover */
}
```
