## 🎨 Design Features

### **Colors Used**
```
Primary Blue:    #2563eb
Dark Navy:       #0f1f4b
Pink/Magenta:    #ec4899
Light Blue:      #f0f9ff, #e0f2ff
Light Pink:      #fce7f3
```

### **Typography**
```
Hero Title:      64px, 900 weight
Section Title:   36px, 800 weight
Card Title:      18px, 700 weight
Body Text:       16-18px, 400-500 weight
Labels:          14px, 600 weight
```

### **Spacing**
```
Hero padding:     80px vertical
Section padding:  80px vertical
Grid gap:        32px
Button gap:      16px
Card padding:    24px
```

### **Animations**
```
Hover lift:      translateY(-12px)
Image zoom:      scale(1.1)
Smooth timing:   0.3-0.4s
Easing:          cubic-bezier(0.34, 1.56, 0.64, 1)
```
