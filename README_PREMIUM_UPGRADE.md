## 🎨 Design System

### New Color Tokens
```css
--navy: #0a1628 (darker, richer)
--blue: #3b82f6 (brighter)
--accent: #818cf8 (purple)
--blue-glow: #2563eb
--accent-bright: #a5b4fc
```

### New Shadow System
```css
--sh-md: 0 8px 32px rgba(15,31,75,.12)
--sh-xl: 0 32px 80px rgba(15,31,75,.20)
--sh-2xl: 0 40px 100px rgba(15,31,75,.25)
```

### New Effects
```css
Glassmorphism: backdrop-filter blur(10-20px)
Gradients: Multi-stop (3 colors)
Animations: Bounce, spring, ease timing
Shadows: Multi-layer with glow
```
